# 09 决策记录与证据索引

## 关键架构决策

| 编号 | 决策 | 理由与约束 | 重评条件 |
| --- | --- | --- | --- |
| ADR-01 | 服务器个人工作空间 | 跨设备访问同一权威服务；不是离线双写文件库 | 明确离线编辑和冲突合并需求 |
| ADR-02 | 模块化单体，API/Worker 分进程 | 统一事务与契约，避免过早分布式复杂度 | 实测独立扩缩与团队边界确有需要 |
| ADR-03 | Rust + PostgreSQL + 私有原件库 | Rust 执行业务边界，数据库管理结构化事实，文件保真 | 保持数据与安全合同的迁移方案成熟 |
| ADR-04 | 稳定身份与不可变修订分开 | 旧知识、发布、笔记与依据可复现 | 不以省存储理由静默覆盖历史 |
| ADR-05 | 原文 + 个人插入层 | 连续阅读并保持来源、位置与归属清晰 | 多人实时共同编辑需要独立设计 |
| ADR-06 | PostgreSQL 首版承担关系查询 | 正文、授权和关系共用权威事务；两场景合成基准作为选型参考，不代表真实产品容量 | 真实数据与变更证明图投影收益 |
| ADR-07 | Neo4j 非首版常驻组件 | 需额外维护同步、撤权、就绪与重建 | 完整权限与投影恢复另验 |
| ADR-08 | outbox + 数据库租约 fencing | 持久重试、接管与结果收敛，不承诺只执行一次 | 外部副作用增加时设计独立幂等合同 |
| ADR-09 | C3 范围交换与 C4 灾备分开 | 范围包不保存全库身份、授权、可变 head 与所有资产 | 不允许仅更名就升级为灾难恢复备份 |
| ADR-10 | 独立见证后才 complete | 同机校验不抵御整机故障 | 独立目标及受信构建完成实测 |
| ADR-11 | 恢复绑定具体目标、会话与锁 | 同 ID/OID 克隆不能代替精确端点 | 实际导入子进程保持并另验这条链 |
| ADR-12 | AI 作为建议层 | 关闭 AI 仍能学习；判断基于事实与条件 | 任何执行/自动发布都先明确授权与回滚 |

这些编号是此次整理的文档索引，不是新的批准或功能变更。已有批准方向保持不变；实际导入与独立备份等待定合同仍需相应设计和验收。

## 数据库实验的历史边界

早期 PostgreSQL/Neo4j 合成两场景基准支持首版技术顺序，但总合同为 NOT_PASSED：补充权限检查存在四项失败。后续 Rust 内核按正式权限合同完成对应阶段验收，不能反向改写旧实验为通过。

实验不能证明所有图查询都更快，也不能将进程内数据库调用时间当作完整产品延迟。后续引入 Neo4j 时须重新验证权限、同步、就绪、乱序、撤权与重建。
