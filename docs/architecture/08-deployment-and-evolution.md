# 08 部署运维与架构演进

## 当前与目标部署

当前仓库的 Compose 文件服务隔离测试、Worker 验收和 C3。Task9 使用真实 S 与独立 D 的候选资源，源上两个实验 guest 分别证明 S1 和 S2。它们共享 S 的物理故障域。应用目标为私有 Linux 部署，同源 HTTPS 接入 API，PostgreSQL、原件、staging 与 Worker 在私有边界内运行。管理与恢复入口分开。

![隔离验收环境与未来应用部署](../diagrams/knowweave-deployment.svg)

| 区域 | 最小职责 | 依赖的验证 |
| --- | --- | --- |
| Web/API（待建设） | 身份、受限命令、用户投影、受控下载 | 浏览器端到端、会话、授权错误和缓存策略 |
| PG 与原件 | 权威事务和原始字节 | 附加迁移、权限、文件完整性与容量 |
| Worker | 专用受限身份、租约和幂等结果 | 旧 token 拒绝、撤权、进程接管、外部效果对账 |
| 源管理 | 维护窗、捕获、原操作和负 fence | 独立审查的 root/PG/control、固定视图与进程证据 |
| 独立 D 与恢复目标 | 独立托管、正常签收、恢复演练 | 管理和传输身份分开；实际链、干净目标和零源依赖回读 |

程序、PG 数据、原件、暂存、可重建派生、备份和证据分别留存。运行身份只读所需发布物，写权限按职责逐项核对。普通 Worker 与后续 HTTP 服务没有备份签发或恢复权限。宿主 root 和 Docker daemon 属于可信运维边界。两端私钥由所属主机 root 托管，发布文档只保存证据索引和允许公开的摘要。

## H4 当前实施边界

C 先完成 S1/S2 离线 PG18 与固定视图，再以实际身份冻结 source-binding、源角色 ELF 和安装对象。D 端曾完成真实 pin 构建及锁定专用账号的准备。权限、trust、固定启动和 22229 的准确范围应在安装前再审。独立目标的容量和可达性按执行时的观测重新核对。旧 HOLD 的资源不可直接重新开机或作为后续成功实例。[隔离资源与构建](../task9/h4-c-isolated-resources-and-build.md) · [安装和双机顺序](../task9/installation-and-two-host-acceptance-plan.md)

新临时 QEMU 单元的首启证据明确包含进程与 InvocationID、`pids.max/current/peak/events`、单元内核拒绝日志及精确停机。峰值结论限定到最后一次有效采样。编排前置优先核对身份、磁盘、路由冲突、挂载模式、任务计数接口、内存余量和证据目录；阶段需要实际运行才能观察的门，由当次受控运行提供。[首启封存单](../task9/h4-c-pg18-first-boot.md)

## 发布、回退与现场留存

1. 冻结发布源、工具链、构建参数、应用和管理 ELF、迁移清单、镜像和配置。已有旧版升级证据按受影响性采用；新协议、schema 或权限改动须重新列回归矩阵。
2. 现场启用前回读准确身份和命令，确认未复用先前目标。失败或返回不明时按精确 ID 停止并保留，再决定是修复、重新准备还是继续 HOLD。
3. 应用版本回退需证明 schema 兼容；内容回到旧修订属于业务动作；数据库恢复需新的干净目标和已验收备份。fence 可能产生持久影响，异常解除另审。
4. 优先清理可重建的编译缓存。在路径、卷、容器及证据引用均核对后精确清理。共享镜像层的估算不累加；保留 H4 和 C4 的源、受审二进制、日志及必要证据。原件垃圾回收需先验证引用和备份保留集。

## 首次测量与后续演进

| 指标 | 采样区间 | 用于决定 |
| --- | --- | --- |
| PG 写入维护窗 | 写入阻断→runtime 允许恢复 | 是否需要把更多校验移出维护窗并重新验收 |
| 备份新鲜度及传输 | 一致快照点→D 完成签收；记录逻辑资产/唯一字节 | 首次确定可承诺的 RPO、容量和增长边界 |
| RA/RB 恢复耗时 | 干净目标准入→完整校验和可用性结论 | 建立 RTO 基线，单列零源依赖路径 |
| API 与后台 | 成功与拒绝延迟、排队、失败、重试和容量 | P1 试用和处理器优先级 |
| 资源保护 | PG、QEMU 和各管理进程峰值、IO、磁盘空间；记录时钟来源 | 工程资源预算与准入，区分未观测值和零 |

当前没有足够实测承诺 RPO、RTO、生产吞吐或持续容量。先测获准批次；目标值和告警随后定。首版继续用 PG 授权图和私有文件库。对象存储或 Neo4j 投影须由真实负载支持，附带撤权、就绪、重建和备份闭包验证。AI 与任意执行器按独立权限和副作用模型评审。
